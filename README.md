1. Project Overview

This project focuses on analysing a Brazilian e-commerce dataset using SQL in Google BigQuery.

The analysis explores customer information, order trends, payment patterns, seller performance, freight costs and delivery operations.

The objective is to extract meaningful insights from the dataset by answering 17 business-related questions using SQL.

2. Project Objectives

* Analyse customer and order information.
* Identify monthly and yearly order trends.
* Understand customer distribution across different states.
* Analyse payment methods and instalments.
* Evaluate order prices and freight costs.
* Measure delivery performance.
* Develop practical SQL data analysis skills.

3. Tools & Technologies

* Google BigQuery

4. Business Questions – 17 SQL Queries

Data Exploration & Order Trends

1. Identify the data types of all columns in the customers table.
2. Find the time range between which orders were placed.
3. Count the cities and states of customers who placed orders.
4. Analyse whether the number of orders has increased over the past years.
5. Identify monthly seasonality in the number of orders.
6. Determine the time of day when Brazilian customers mostly place orders.
7. Calculate month-on-month orders placed in each state.
8. Analyse customer distribution across all states.

Economic & Financial Analysis

9. Calculate the percentage increase in order costs from 2017 to 2018 (January–August).
10. Calculate the total and average order price for each state.
11. Calculate the total and average freight value for each state.

Delivery Performance Analysis

12. Calculate delivery time and the difference between estimated and actual delivery dates.
13. Identify the top 5 and bottom 5 states based on average freight value.
14. Identify the top 5 and bottom 5 states based on average delivery time.
15. Identify the top 5 states where orders were delivered faster than the estimated delivery date.

Payment Analysis

16. Analyse month-on-month orders based on different payment types.
17. Analyse the number of orders based on payment instalments.
